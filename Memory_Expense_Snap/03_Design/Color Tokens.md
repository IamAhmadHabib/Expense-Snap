# Color Tokens

Use `kharcha/lib/theme/app_colors.dart`.

Core tokens:

- Background: `#FAF8F4`
- Primary: `#1C1C1E`
- Surface: `#FFFFFF`
- Surface variant: `#F0EDE8`
- Accent: `#E5A33C`
- Success: `#34C759`
- Danger: `#E8634A`
- Header card: `#141210`

Forbidden:

- Purple.
- Teal.
- Bright blue.
- Flutter default blue.
