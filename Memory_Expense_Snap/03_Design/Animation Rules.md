# Animation Rules

Motion should feel premium and physical:

- Gentle rise.
- Soft blur.
- Radial reveal.
- Breathing mic rings.
- Sliding tabs.
- Count-up stats.
- Meaningful haptics.

Avoid:

- Cheap bounce.
- Distracting loops.
- Motion that slows expense capture.
